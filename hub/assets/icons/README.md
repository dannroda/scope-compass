# icons

Tema de íconos del systray. `hicolor/scalable/apps/scope-compass.svg` es `node/compass.svg` de @icons v1.5.0, de Voxy (Valentin Fossati) y colaboradores (MIT, ver `LICENSE-at-icons.txt`), pintado con el dorado de la interfaz (`#d9a441`), como `web/favicon.svg`. `scope-compass.ico` es el mismo dibujo para Windows (la bandeja y el acceso directo de `install.ps1`); lo arma `node tools/make-ico.mjs` desde el SVG.
